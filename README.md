Real-time 3D network traffic visualization on an interactive globe. Simulated connections appear as animated arcs from origin to destination, color-coded by protocol.

**[Live Demo](https://megatron54.github.io/NetGlobe/)**

## Overview

NetGlobe renders network connections as animated arcs on a 3D WebGL globe. Each connection is mapped to a geographic destination and drawn in real time with protocol-based color coding. Traffic data is **generated by a client-side simulation** (see `src/hooks/useTraffic.ts`) that produces realistic connection patterns, volumes, and protocol distributions — this is a visualization/UI project, not a live packet capture tool.

## Features

- Interactive 3D globe with a high-resolution night-sky Earth texture
- Animated arcs showing active simulated connections from origin to destination
- Protocol classification with color coding (HTTPS, DNS, UDP, TCP)
- Live connection list with IP, location, protocol, and data volume
- Traffic statistics panel: active connections, bandwidth, packets/sec
- Top destination countries with visual breakdown
- Smooth orbit controls with damping

## Tech Stack

- **React 19** + TypeScript (strict mode)
- **globe.gl** — WebGL globe rendering with arc/point/ring layers
- **Tailwind CSS 4** — utility-first styling
- **Vite 7** — build tooling
- **GitHub Pages** — static deployment via GitHub Actions

## Protocol Colors

| Protocol | Color | Description |
|----------|-------|-------------|
| HTTPS (443) | Sky blue | Encrypted web traffic |
| DNS (53) | Amber | Domain resolution |
| UDP | Violet | User datagram protocol |
| TCP | Emerald | General TCP connections |

## Quickstart

```bash
git clone https://github.com/megatron54/NetGlobe.git
cd NetGlobe
npm install
npm run dev
```

Open `http://localhost:5173/NetGlobe/`.

## Build

```bash
npm run build
npm run preview   # preview the production build locally
```

## Project Structure

```

├── components/
```
